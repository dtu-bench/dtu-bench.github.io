Dynamic Task Update Benchmark (DTU-Bench):Evaluating Runtime Task Adaptation in Robotic Manipulation

Yanran Jiang1, Cécile Paris1, Dana Kulić1,2, and Leimin Tian1

1CSIRO Technology, Australia
2Monash University, Australia

PDF Paper ▶ Video

Can a robot revise a task it has already started? DTU-Bench pairs original and updated language instructions in the same LIBERO scene. Across 40 task revisions and 13 vision-language-action policy configurations, it measures whether the robot reaches the new goal, how it gets there, and whether the goal still holds at the end.

Abstract

Vision-language-action (VLA) policies perform well on fixed-instruction robotic manipulation benchmarks, but their ability to adapt to instruction changes during execution remains understudied. We introduce the Dynamic Task Update Benchmark (DTU-Bench), evaluating 40 task revisions across seven update types and three execution stages using LIBERO, a simulated robotic manipulation benchmark. We compare performance when a new instruction is given before execution starts versus during execution, and examine whether the new task instructions are followed. Across 13 representative VLA configurations, average task success is 95.8% on the original object-manipulation tasks, compared with only 1.6% when the instruction changes which object to manipulate during execution. Controlled diagnostics show that policies often complete the original task before the updated one, and that their responses depend on the robot's physical state. We further test whether a simple scripted controller that releases the grasped object and moves the arm back helps robots respond to instruction changes. This improves success from 2% to 38% for π0.5 and from 8% to 48% for DM0.5, but can cause unwanted object motion. These findings reveal limitations that fixed-instruction benchmarks and task-success metrics alone can overlook in evaluating robotic manipulation.

Finding 1. Not All Task Updates Are Equally Difficult

Changing the destination is often easier than selecting another object.

Across the evaluated configurations, destination updates yield 36.4–68.8% runtime Final success. Object-identity updates reach at most 13.5%, and spatial-referent updates at most 1.2%. Each interval runs from the lowest to the highest observed policy rate.

Key insight A destination change can preserve a useful grasp. Scene layout and manipulation difficulty also vary across categories, so these differences alone cannot isolate the effect of the update type.

Finding 2. Task Competence Does Not Imply Runtime Adaptability

The same instruction can succeed from the start and fail after the robot has begun another task.

On compound goals, OpenVLA-OFT sustained the updated goal for ten consecutive observations in 244/250 updated-from-start trials (97.6%), compared with 7/750 valid scheduled runtime trials (0.9%). The paired gap is 96.7 percentage points. Both conditions score the same updated goal.

Matched example: from-start success, runtime failure

Key insight Giving the revised instruction from the start tests whether the policy can perform the task. Delivering it during execution tests whether the policy can redirect behavior from a state reached under the old task.

Finding 3. Later Task Updates Are Not Always Harder

The direction of the timing effect changes with the task.

For DM0.5, destination Held-10 success falls from 64.4% to 58.8% to 48.8% across early, middle, and late updates. Object-identity success rises from 10.2% to 13.0% to 15.2% in the same stage order. Each destination stage has 250 valid scheduled trials and each object stage has 500.

Key insight Interpret timing relative to what remains useful from the original task. An early, middle, or late update represents a physical event in that task.

Finding 4. Goal Attainment Can Mask Adaptation Failures

A success score hides both the path to the new goal and what happens next.

Delayed response. Among 192 delivered DM0.5 object updates that achieved updated Held-10, 184 reached the original goal first. The recorded sequence below shows the robot receiving a cream-cheese instruction, placing the alphabet soup, and only then placing the cheese.

Incidental attainment

In 37 of 94 matched pairs, both the original-instruction and updated-instruction branches achieved updated Held-10. All 37 involved terminal-state updates. Following the old instruction could briefly satisfy the new predicate.

Temporary satisfaction

For DM0.5 terminal-state updates, 64.9% achieved Held-10 but only 0.22% still met the goal at Final. A drawer can remain open for ten observations and then close.

Key insight Ever records a single attainment, Held-10 records a sustained interval, and Final tests the last observation. The trajectory reveals whether the robot switched promptly.

Finding 5. Prior Progress and Robot State Shape Task Adaptation

The same words and object layout can lead to different first contacts.

In the controlled DM0.5 object-selection experiment, the first contact matched the instruction in 20/40 saved-posture continuations and 40/40 neutral-posture continuations. The design varied instruction, layout, and posture across two object tasks. The two rows below hold the object layout fixed.

When earlier progress helps

In a separate matched-stage probe, π0 and π0.5 each succeeded in all 10 destination-update continuations. After stable grasp, neither completed the object switch in five attempts per policy, although the updated-from-start controls succeeded.

Key insight Physical configuration can influence object selection. First contact is only one step toward completing the revised task, and these controlled cases explain a subset of failures.

Finding 6. Physical Assistance Can Mitigate Some Adaptation Failures

A fixed-joint retreat helps before grasping. After grasping, releasing the object changes the outcome.

In DM0.5 approach-stage object updates, 4/50 direct trials achieved Held-10, compared with 25/50 after fixed-joint retreat. At stable grasp the counts were 4/50 direct, 1/50 retreat, and 24/50 release-and-retreat. Helper actions used part of the same 300-action budget.

Matched example: release before retreat

Costs of intervention

For π0.5 destination updates at approach, retreat reduced Held-10 from 21/25 to 16/25. At stable grasp, release-and-retreat produced unsupported downward object motion in 49/50 object trials for each of the two policies.

Key insight Physical assistance can recover some object switches without retraining. Its value depends on whether prior progress should be preserved and on the physical consequences of releasing the object.

When does the instruction change?

Each task starts from 50 official initial states. Original-from-start and updated-from-start controls establish performance on the two instructions independently. Three runtime conditions deliver the update at task-specific physical events. For pick-and-place tasks, these are approach, stable grasp, and transport. At delivery the evaluator discards queued actions, requests fresh inference, and allows 300 executed actions from the reached state.

How is success measured?

Ever
The goal holds after at least one executed action.
Held-10
The goal holds for ten consecutive executed-action observations.
Final
The goal holds at the last evaluated observation.

Overall Conclusion

Following a task from the start and revising it mid-execution are different capabilities. Across the tested policies, destination changes often preserve useful progress, while object switches can require undoing it. The controlled continuations show why both the robot’s physical state and the sequence of goal attainments matter when interpreting success.

A runtime evaluation should ask three questions: Could the robot do the revised task from the start? Did its behavior change after delivery? Did the new outcome persist?
